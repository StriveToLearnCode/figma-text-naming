# Figma 文本语义词典

本词典只帮助理解 Figma 动态文本的业务语义，以及选择 `Page_Module_txtNN` 中稳定的 Page 和 Module。它不是下游数据映射表，也不定义运行时代码。

## 业务域词表

| 业务域 | 适用语义 | 有效 Figma 证据 |
| --- | --- | --- |
| `lottery` | 抽奖、开奖、抽取次数和抽奖结果 | 图层、组件、区域或相邻标签明确包含抽奖、开奖、转盘、扭蛋等含义 |
| `reward` | 独立奖励模块中的奖励名称、数量和领取状态 | 稳定区域明确为奖励、奖品、奖励列表或领奖模块 |
| `task` | 任务进度、完成状态和任务奖励 | 稳定区域明确为任务、目标、每日任务或阶段任务 |
| `rank` | 排名、积分和榜单状态 | 稳定区域明确为排行榜、名次、积分榜或段位榜 |
| `shop` | 商店中的价格、库存和限购数量 | 稳定区域明确为商店、兑换、商品或购买模块 |

优先使用明确产品/设计命名、稳定组件或区域、同页面已确认的相同功能。不要用 `板块4` 等位置型容器名代替语义。业务域可作为 Module 候选；Figma 文件已有稳定 Module 标识时优先沿用。

## 标准语义词表

| 标准词 | 含义 | 常见中文证据 |
| --- | --- | --- |
| `current-count` | 当前已经拥有、使用或发生的次数 | 当前次数、已有次数、已抽次数 |
| `remaining-count` | 仍可使用或尚未完成的次数 | 剩余次数、可用次数、还可抽 |
| `total-count` | 总次数或累计数量 | 总次数、累计次数、总数量 |
| `countdown` | 随时间递减的剩余时长 | 倒计时、剩余时间、距开启 |
| `progress` | 当前进度值或进度比例 | 当前进度、完成进度、幸运值进度 |
| `multiplier` | 奖励、得分或产出的倍率 | 倍数、倍率、翻倍 |
| `reward-name` | 当前奖励或奖品的名称 | 奖励名称、奖品名称、获得物品 |
| `reward-count` | 当前奖励或奖品的数量 | 奖励数量、奖品个数、获得数量 |
| `current-rank` | 当前用户或条目的名次 | 当前排名、我的名次、当前段位 |
| `score` | 排行或任务使用的积分值 | 积分、分数、榜单分值 |
| `price` | 商品购买或兑换所需价格 | 价格、售价、兑换消耗 |
| `stock` | 商品当前库存 | 库存、剩余库存 |
| `completed` | 已完成状态 | 已完成、任务完成 |
| `claimed` | 奖励已领取状态 | 已领取、领取完成 |
| `locked` | 尚未解锁状态 | 未解锁、尚未开启 |

这些词用于理解语义和选择简短 Module，不要求把完整业务含义编码进名称。`current-count`、`remaining-count` 与 `total-count` 不得互换。文本只有占位符时，必须从图层、祖先、相邻标签、组件或变体状态取得限定信息，否则进入 `confirm`。

## 组件语义模式

| 组件 | 常见语义 |
| --- | --- |
| 抽奖 | 当前抽奖次数、剩余抽奖次数、抽奖倒计时、奖品名称 |
| 奖励 | 奖励名称、数量、领取状态 |
| 任务 | 任务进度、任务奖励数量、完成状态 |
| 排行 | 当前名次、榜单积分 |
| 商店 | 商品价格、库存、剩余可购次数 |

组件模式只在 Figma 证据成立时使用。文案出现“奖励”不代表 Module 一定是 `reward`；抽奖组件中的奖品名称通常仍属于抽奖上下文。

## 证据治理

- 有意义的原图层名可以作为证据，例如 `当前抽奖次数`、`奖励倍数`、`商品库存`。
- `Frame 123`、`Group 8`、`板块4`、`文本`、`数字`、`xx` 不构成业务语义证据。
- 只有视觉位置、通用页面习惯或模型猜测时，不得确定语义。
- 新语义词只用于解释和复用判断；孤立或含义不清的文本等待用户确认。
