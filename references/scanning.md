# 扫描范围

本文件只负责根据用户提供的 Figma URL 确定本次扫描范围。

## 可扫描范围

任何可访问的 Figma 文件、页面或节点都可以作为扫描入口，不要求页面名、Frame 名或节点类型符合特定格式。`翻译页面[...]`、`预览图/*` 等名称只作为命名时的业务上下文，不是扫描准入条件。

根据用户提供的链接确定扫描根节点：

- 链接包含 `node-id` 时，以该节点本身作为扫描根节点，不自动提升到特定 Frame 或页面；
- `node-id` 指向 `TEXT` 时，扫描该文本节点本身；
- `node-id` 指向页面或其他容器节点时，扫描该节点的全部后代；
- 链接未提供 `node-id` 时，扫描该文件内全部可访问页面；
- 用户提供多个链接时，合并各链接选中的扫描根节点，并按节点 ID 去重；
- 一个扫描根节点已包含另一个根节点时，只保留范围更大的根节点，避免重复扫描；
- `node-id` 不存在、无权访问或无法读取时，将该链接标记为失败，不得静默扩大到整页或整个文件。

扫描根节点本身及其全部后代 `TEXT`，包括隐藏节点。

候选占位符的识别规则由 [naming-rules.md](naming-rules.md) 负责。

## 扫描要求

- 当前名称已经合法的候选仍须参与扫描，不得直接跳过；
- 同一页面内，本次选中的多个扫描根节点可以共同去重；
- 链接已经限定节点时，其父级、同级和范围外节点不得纳入本次扫描；
- 不得跨 Figma 页面自动去重；
- 实例继承或只读文本可以记录，但不得直接改名；
- 后续去重和命名所需的数据按对应规则读取，不在本文件固定内部快照结构。
