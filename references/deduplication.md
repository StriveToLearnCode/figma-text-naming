# 去重规则

本文件只负责判断当前链接所选扫描范围内的候选文本是否相同。

本次选中的多个扫描根节点位于同一 Figma 页面时可以共同去重，但不纳入链接所选范围之外的节点，也不跨 Figma 页面去重。

## 核心规则

两个候选只有同时满足以下条件时，才视为相同文本：

1. 规范化后的文字完全一致；
2. 规范化后的文字样式完全一致。

文字或样式任意一项不同，都视为不同文本。

可以等价理解为：

```ts
const isSame =
  textSignatureA === textSignatureB && styleSignatureA === styleSignatureB;
```

## 文字比较

为每个候选生成 `textSignature`。

比较前只进行以下规范化：

- Unicode 统一为 NFC；
- CRLF 和 CR 统一为 LF；
- 每个动态占位符统一表示为 `{{}}`；
- 清理不影响展示的行尾空白。

除此之外，不修改正文。

以下任意一项不同，都视为文字不同：

- 文字内容；
- 占位符数量；
- 占位符位置；
- 占位符顺序；
- 换行；
- 正文空格；
- 标点。

例如，以下文本均视为不同：

```text
当前次数：{{}}
当前次数 {{ }}
当前次数：
{{}}
剩余次数：{{}}
```

## 样式比较

为每个候选生成 `styleSignature`。

样式签名按规范化文本中的字符范围，记录影响视觉表现的样式。

当前至少比较：

- 文字颜色；
- 字号；
- 字重；
- 每段样式实际作用的字符范围。

比较前应先规范化等价样式：

- 等价颜色统一为相同颜色值；
- 字号统一为相同数值单位；
- 字重统一为规定的数值；
- 连续且完全相同的样式片段合并。

以下任意一项不同，都视为样式不同：

- 样式值不同；
- 样式作用范围不同；
- 样式片段顺序不同；
- 占位符上的样式不同。

例如，两个节点的文字均为：

```text
当前次数：xx
```

但一个节点中的 `xx` 为金色，另一个为紫色，应视为不同文本。

即使颜色值相同，但一个节点只对 `xx` 设置颜色，另一个节点对整句话设置颜色，也应视为不同文本。

## 比较流程

为减少无效样式读取，按以下顺序执行：

1. 第一阶段只生成并比较 `textSignature`。
2. `textSignature` 不同的候选直接视为不同文本，不再比较样式。
3. 将 `textSignature` 相同的候选分组。
4. 批量读取这些重复文字组需要的样式字段。
5. 在每组内部比较 `styleSignature`。
6. `textSignature` 和 `styleSignature` 都相同的候选归为同一组。
7. `styleSignature` 不同的候选拆分为不同组。

同一组内可以包含来自本次选中且位于同一页面的不同扫描根节点的候选。

## 不参与去重的信息

以下信息不得进入 `textSignature` 或 `styleSignature`：

- 当前图层名称；
- 候选 Key；
- Figma 页面 ID；
- 节点 ID；
- Frame 名称；
- 父级路径；
- 相邻文案；
- 组件或变体；
- 158、388 等区域标识；
- 视觉位置；
- 节点顺序；
- 可见性；
- 业务语义；
- 中文翻译；

这些信息可以由其他流程用于理解语义、选择名称、排序或定位节点，但不得改变去重结果。

不得因为候选位于不同 Frame、组件、区域或视觉位置而将相同文字拆开。

不得因为候选业务含义相近、中文翻译相似或编辑距离较小而合并不同文字。

去重组只回答文字和样式是否完全相同，不直接决定业务 Key 是否必须不同。不同去重组只有在 [naming-rules.md](naming-rules.md) 规定的语义等价关系成立时，才可以共用业务 Key；它们仍须报告为不同精确去重组，不得改判为 `same`。

## 无法比较

出现以下情况时，该候选或分组返回 `confirm`，不得猜测是否相同：

- styled text segments 缺失；
- 样式片段无法覆盖全部字符；
- 样式片段范围重叠或顺序异常；
- 无法确定样式实际作用范围；
- 存在当前规则无法可靠规范化的展示样式；
- 样式数据相互冲突；
- 无法排除有意义的样式差异。

## 判断结果

去重流程只返回以下结果：

- `same`：规范化文字和规范化样式都完全一致；
- `different`：文字或样式至少有一项不同；
- `confirm`：样式数据不足或无法可靠比较。

本文件不负责生成 Key、选择名称、处理名称冲突、分配样式编号、修改 Figma 或生成用户汇报。
